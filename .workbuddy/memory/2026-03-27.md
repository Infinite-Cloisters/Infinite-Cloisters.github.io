# 2026-03-27

## 修复 Sphinx ?v= 查询字符串导致 GitHub Pages 404

- **问题**：Sphinx (sphinx_rtd_theme) 生成的 HTML 文件中，CSS/JS 引用带有 `?v=哈希值` 缓存破坏参数，GitHub Pages 静态服务器无法处理带查询字符串的文件请求，导致 404。
- **解决方案**：新增 `strip_query_strings.py` 后处理脚本（项目根目录），用正则 `\?v=[0-9a-f]+` 批量清除 docs/ 下所有 HTML 文件中的 `?v=` 后缀。
- **已修改文件**：
  - `strip_query_strings.py`（新增）
  - `build.ps1`（末尾添加 `python strip_query_strings.py ./docs`）
  - `build.sh`（末尾添加 `python strip_query_strings.py ./docs`）
- **已处理**：4 个 HTML 文件（docs/index.html, docs/search.html, docs/doc/wsl/index.html, docs/doc/wsl/wsl.html）立即修复。
