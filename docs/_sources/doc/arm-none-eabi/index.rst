

ARM Toolchain
=========================
这里主要介绍使用keil5之外的arm toolchain进行单片机开发的相关内容,主要是arm-none-eabi工具链和gdb调试器的使用.

有时候,我不太能理解有些人喜欢手动给安装改路径,是portable版本倒是没问题,但如果是安装版本,那就是自找麻烦!

这些软件往往还会在你的C盘拉一堆文件,即使你把应用路径放在别的盘上。重装系统时候也只保留本体,注册表、环境变量全无,有的甚至直接不能用.

我个人比较推崇双盘用户选择:大C盘+D盘(可以是别的盘)放工程文件+E盘放大型下载的资料/大型游戏的方式,一能降低文件管理成本,二是能让文件存放符合直觉更好管理.
