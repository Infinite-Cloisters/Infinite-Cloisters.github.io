西北工业大学科技论文写作
==============================

这里是《科技论文写作》课程三次 LaTeX 实验课的实验题解答。

课件中每道实验题都给出了\ **题目**、\ **提示**\ 和\ **代码框架**，框架里用注释标出了需要补全的位置（如 ``% 补全公式``）。本文档在这些框架的基础上补全全部空缺，给出\ **可直接编译的完整代码**，并补充编译方式与常见报错说明。

开始做实验之前，建议先读一遍「环境准备」——那里讲了 TeX 发行版的安装、镜像源的配置，以及缺宏包时怎么补装。

三次实验课的内容分别是:

- 实验课 01：公式、表格、图等
- 实验课 02：列表、算法、颜色等
- 实验课 03：绘图（选学，TikZ 与 pgfplots）
